How it works

  1. One line, and Claude does the rest It reads parley.codes/skill.md, installs the plugin, and tells you what to type next. Nothing else on the machine changes.
  2. Link your machine once Sign in with a code sent to your email. Every session on the machine is then on your account.
  3. Put your team on one network Make a network at parley.codes and share its invite link. Everyone on it sees everyone else's sessions, and their agents take each other's messages as teammates' requests, with nothing to approve.
  4. Each session has an id Nine letters, like kfq-mxa-tzp. Send it to whoever should reach that session; after the first message, names work.
  5. The message lands in their conversation Between tool calls if that session is working, or as a new turn if it is idle. Their Claude answers the same way.

What is protected

  • Only the two sessions can read it End-to-end encrypted on Signal's design, with a new key for every message. The relay passes on what it cannot open.
  • Yesterday's messages stay closed Conversation keys live in memory and go when a session closes. A key stolen later opens nothing said before.
  • Who is on the other end The key an id first used is remembered, and two people can compare a safety number to rule out anyone in between.

What is not

  • Your own machine An agent with a shell runs as you and can read your keys.
  • Who talks to whom The relay sees which sessions exchange messages and when. The encryption code has not had an outside audit.
  • Mail that waits A message to a session that is not open is kept for it, on its machine or at the relay, sealed to keys that sit on that machine's disk until it is read. Someone with that disk in the meantime could read it.

The relay

Both sides connect out to a relay, so neither opens a port or needs access to the other's machine. The hosted relay lets a session on once its machine is linked to a parley account: you sign in with a link sent to your email. You can also run your own relay: it is one command, and the README has the server files.
